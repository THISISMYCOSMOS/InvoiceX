# Different-format blind evaluation v1

회사마다 문서 양식이 다르다는 조건을 반영해 ERP 그리드, 수출 상업문서, 이중언어 사이드바, 2페이지 법률형, 카드형, 레거시 단색, 가로형 조달, 래스터 스캔 등 8종을 블라인드 평가했습니다.

- 설계 8세트(32 PDF), 측정 7세트, 미측정 1세트
- 측정 문서 28/28, 필드 392/392, 불일치 5/5
- u08 래스터 전용 스캔은 두 번 모두 HTTP 503이라 의미 정확도 미측정
- 호출 11회 중 유효 구조화 결과 7회(63.6%)

`results/summary.json`은 최종 고유 사례 기준 집계이며, u01~u08 JSON은 선택한 최종 원시 결과입니다. u03 타임스탬프 이상 때문에 사례별 지연시간 통계는 제외했습니다.
